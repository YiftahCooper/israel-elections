# Candidate biography links (`data/meta/bios/kNN.json`)

Research data for a planned feature: from any candidate in the app, link to an **official
biography** (the Knesset's member page, or the candidate's own party's site at the time of the
election) and to a **neutral encyclopaedic biography** (Hebrew Wikipedia, a labelled secondary
source). These files are evidence records, not part of the immutable election datasets in
`public/data/`. They are generated by `scripts/research/build-bios.py` from retained inputs in
`data/raw/bios/`; the method, coverage and every left-out case are in
[docs/research/candidate-bios.md](../../../docs/research/candidate-bios.md).

**No English-language Wikipedia link or source is used** (owner rule). Hebrew Wikipedia is the
only encyclopaedia, and is secondary. **No identity is guessed**: a candidate has an entry only
when an official identifier or a documented unambiguous rule ties the dataset name to the person.

## Format

One file per election. Only candidates with at least one link appear. Keys are the candidate ids
of `public/data/kNN.json` (`"<knesset>-<letters>#<rank>"`).

```jsonc
{ "electionId": "k25",
  "generatedBy": "scripts/research/build-bios.py",
  "format": "data/meta/bios/README.md",
  "candidates": {
    "25-מחל#1": {
      "knessetPersonId": 965,                 // Knesset OData KNS_Person.PersonID, or null
      "knesset": {                            // official Knesset member page, or null
        "url": "https://main.knesset.gov.il/mk/apps/mk/mk-personal-details/90",
        "siteId": 90,                         // the website's member id (OData KNS_MkSiteCode.SiteId)
        "verified": "pattern" },              // see below
      "hewiki": {                             // Hebrew Wikipedia article (secondary), or null
        "title": "בנימין נתניהו",
        "url": "https://he.wikipedia.org/wiki/%D7%91%D7%A0%D7%99%D7%9E%D7%99%D7%9F_...",
        "via": "wikidata Q43723" },           // the Wikidata item that links the person to the article
      "party": {                              // the party's own biography of the candidate, or null
        "url": "https://web.archive.org/web/20221020000000/https://...",
        "original": "https://...",            // the page as published by the party
        "archivedAt": "2022-10-20",           // date of the capture (null for a live page)
        "publisher": "יש עתיד",
        "kind": "archive",                    // party-site (live) | archive (Wayback capture of the party site) | social
        "note": "…" },                        // optional, e.g. a list page rather than a personal page
      "confidence": "high",
      "basis": "elected; Knesset 25 member, name identical (3)" } } }
```

### `knesset.url`

`https://main.knesset.gov.il/mk/apps/mk/mk-personal-details/{siteId}`. The website does **not** use
the OData `PersonID`: it uses its own member id, which OData publishes in `KNS_MkSiteCode`
(`KnsID` = PersonID, `SiteId` = website id). The pattern is confirmed by archived official pages
(see the research note). `verified` is `"pattern"` (built from the official id mapping) or
`"archive YYYY-MM-DD"` when that member's page was itself loaded from a Wayback capture and showed
the member's name. knesset.gov.il serves a bot challenge (HTTP 247) to scripts, so live pages were
not loaded. Members of the 26th Knesset elected for the first time have a `knessetPersonId` but no
site id yet (OData has not published one before the 10 November 2026 opening), so they have no
Knesset link; they appear only if another link exists.

### `confidence`

- **high** — an elected member matched to that Knesset's membership by name within the list's
  factions; or a reviewed decision with documentary support (earlier surnames, printed forms,
  short given names; `data/raw/bios/identity-decisions.reviewed.json`); or a non-elected candidate
  who entered the same Knesset in the list's faction (a replacement).
- **medium** — the identity rests on an exact name plus party lineage, without an official
  identifier tying the candidacy to the person: a non-elected candidate whose name is identical to
  exactly one person who ever served as an MK, in the same party lineage, in the adjacent Knesset (or
  two or three Knessets away when the surname is unique among MKs or the person's Hebrew Wikipedia
  article places them in this election); a non-MK candidate whose name is identical to exactly one
  Wikidata person recorded as a member of the list's party, adult at the election, whose Hebrew
  Wikipedia article places them in this election; or a reviewed decision with an unexplained
  given-name difference. An entry is medium if any of its links rests on such a rule.

`basis` states the rule that produced the entry, in English, for audit.

K25 audit correction (6 November 2026): repeated spaces in the 21 English names emitted for k25 were collapsed in the shared English-header input. Each changed row preserves the exact retrieved string in `nameEnRaw`; `nameEn` is its whitespace-normalized display form. The site id and API route above identify the rank-1 source for each name. This also corrects the same people wherever that shared input is reused; no spelling or identity changed.
