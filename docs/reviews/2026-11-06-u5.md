# U5 — header targets and edited annotations

Branch: `t3/polish-topbar-and-edit-marker`. Base: `53cca36c5a2c3442d64ebc40835139a5d93106b3`, fast-forward check against `origin/main` completed before edits. No merge to main or push.

## Changes and audit

- Election previous/next: 34px desktop targets, 44px phone/coarse-pointer targets; 6px separation, centred alignment and mirrored arrows in RTL.
- Election and scenario pickers: same button surface, spacing and paired-chevron dialog affordance. Shared `ChoicePicker` extends the convention to grouping, comparisons, rule/source choices and every other dialog picker. The header scenario name stays on one line (ellipsis for long names; full text inside the picker) so its first edit never increases header height. Native selects retain native arrows; inline disclosures and action menus retain their downward chevron.
- About: removed the 200px wrapper and phone fixed-width overrides. The summary owns its border, padding and background; the visible box is clickable throughout. Short publication status stays visible, with the full explanation inside About.
- Levels and Custom: matching header control sizes, rounded corners and gaps. Shared segmented controls no longer clip keyboard focus rings; end buttons retain rounded corners.
- Undo/redo/reset, save/share, language and theme: one wrapping action group with consistent targets. The settings gear is absent from this base; a `.tool` gear inherits these styles and the action group wraps when needed.
- Saved scenarios inside Save & share: removed the inherited full-width rule on nested row buttons. Open, Compare and Delete each own their visible target.
- Shared `EditMarker`: removed pill border/fill. Localised underlined “Edited” text remains explicit next to the field. Hover, focus, click/tap and Enter/Space show the reference value. Escape dismisses; Tab reaches restore. The floating dialog is portalled out of surrounding row buttons, with a hover bridge so its action remains reachable. Restore names its scope (e.g. Votes or Rules), uses the existing scenario action, retains undo and resolves against the marker's reference/checkpoint. List-local parts restore that list; section markers restore their named section. Fields with no corresponding part retain their reference explanation.

Audit also checked shared buttons, numeric stepper groups, switch labels, list rows, disclosure controls, choice option rows and form labels. Their actual native controls already own their styled surfaces; no additional partial-box defect was found there. Numeric inputs remain inputs, and composite groups retain distinct bounded subcontrols.

## Marker alternatives

1. Tinted dot plus text: explicit, but adds a second identity cue beside party/scenario colours.
2. Small filled text tag: explicit, but repeats the button-like visual the owner rejected.
3. Underlined text annotation (chosen): the explicit word remains, uses the field's neutral ink, and reads as a contextual disclosure without a bordered pill. It works in dense rows, field labels and replacement summaries.
