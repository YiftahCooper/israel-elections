# k23 independent Codex audit — 2 March 2020

Audited 2026-11-06, baseline `53cca36`, branch `t3/ee136cf9`. Role: auditor; no data edits or dataset build. `git merge --ff-only origin/main` completed with “Already up to date.” No other auditor's report was consulted.

**Counts: OK 48; WRONG 5; UNSUPPORTED 2; UNVERIFIABLE 5; DISPUTED 0.** Counts are **review units**, not a count of individual JSON leaves: 30 list rows, 18 thematic rows, and 12 findings. Repeated manifestations of the same problem count once. In particular, the 1,097 candidate names and 1,214 locality rows are not inflated into thousands of “OK” claims. An OK row covers only the explicitly enumerated fields; open fields are enumerated separately below. This is substantial verification, not a certification of every link, geographic classification or typographic detail.

The national results are sound: every list's votes, letters and seats match the official CEC results. A newly reached primary source, **YP 8736, 10 March 2020, pp.4896–4906**, independently confirms the result and names all 120 elected members. The principal errors concern chronology, source attribution and stale metadata, not seat allocation.
