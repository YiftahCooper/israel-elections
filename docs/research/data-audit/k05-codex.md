# k05 independent audit — Codex

Audited 2026-11-06, against worktree HEAD `68b836a` (contains `53cca36`); `git merge --ff-only origin/main` reported already up to date. Auditor only: no data changes, builds or browser test suites. This report is independent of the other auditor's findings.

## Summary

**30 OK / 7 WRONG / 1 UNSUPPORTED / 5 UNVERIFIABLE / 1 DISPUTED** grouped audit units. Counts are report rows, not individual scalar values: a roster row covers all its transcribed ranks. Related occurrences of one erroneous identity count once. The core 14 vote counts and 11 winning seat counts agree with the gazette; all 122 transcribed candidate ranks were visually compared with the candidate notice and the 120 declared elected identities with the results notice. The serious defects are in losing-list identities and the omitted withdrawn list, not the seat allocation.

Lower-priority checks have explicit limits below. In particular this is **not** a successful verification of every external bio link, every English personal-name spelling, the Liberal logo's original campaign provenance, or exact September consultation datelines. Unknown party recommendations remain unknown, not abstentions.
