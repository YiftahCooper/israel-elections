# k18 independent Codex data audit

Audited 2026-11-06; election 10 February 2009. Baseline `d2c1ed0`, branch `t3/edec80a4`; required `git merge --ff-only origin/main` reported already up to date. Read BRIEF.md and the binding source hierarchy, and skimmed DATA.md and archive-access-routes.md. No dataset edits or build. This report was prepared independently; no other auditor's report was consulted.

**Counts (audit units, not individual scalar fields): OK 43; WRONG 12; UNSUPPORTED 2; UNVERIFIABLE 6; DISPUTED 1.** National table rows are one OK unit each (33); ten additional verified bundles follow. Non-OK units below are separately counted fields/bundles, so a list's correct vote count does not excuse its incorrect label or metadata. Unverified coverage is explicitly included rather than certified by inference. This is a broad audit with remaining verification limits, not certification of every linked biography, transliteration, locality classification or lower-rank affiliation.

The most consequential findings are a mixed-date first-government bloc; incomplete joint-list faction counts despite complete official opening membership; missing Meretz affiliation for elected rank 2; the midnight dissolution vote date; and an unresolved official invalid-ballot conflict. The results gazette **is retained**, its publication date **17 February is correct**, the 33 displayed lists all have positive votes, and the withdrawn 34th list is omitted rather than marked active.
