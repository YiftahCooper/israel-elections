# Independent data audit — k20 (Codex)

Audited 6 November 2026, against baseline `d2c1ed0` (`53cca36` is an ancestor). `git merge --ff-only origin/main` reported already up to date. Role: auditor only. No dataset build, data changes, push or integration merge.

**Grouped audit-unit counts: OK 51; WRONG 6; UNSUPPORTED 0; UNVERIFIABLE 4; DISPUTED 1.** These are the 26 list rows, 25 additional OK rows, and 11 non-OK rows below, not a count of individual JSON scalar values. A list's OK row covers its printed identity, result and registered roster; exceptions and unresolved enrichment claims are separate rows. Do not read this as certification of every enriched biography, constituent affiliation or external endpoint.

The historical vote and seat totals pass. The consequential defects are an unmarked withdrawn list, a missing portable polling input, a candidate spelling discrepancy left unexplained, and overstated affiliation provenance. Physical polling-place counts need a definition/source reconciliation. The recommendation totals and dates **do not** reproduce the errors seen in other elections. The results gazette **is retained**. No reversed-parenthesis defect was found in the four candidate names containing parentheses.

## Evidence and method

All access dates below are **2026-11-06**. Ranks follow `docs/research/source-hierarchy.md`. “Retained” means I read the actual source bytes, not merely a citation or another auditor's conclusion. Official source text and independently retrieved contemporary reports are distinguished below. No other auditor's report was read. English Wikipedia and its mirrors were not used as evidence or leads; unsolicited search hits were discarded.

I independently extracted the three retained PDFs with the installed `pdfjs-dist` 6.5.438, without running dataset code. All 26 vote rows and seat rows were compared; all 1,284 registered names were searched against the candidate notice (1,277 contiguous matches; seven wrapped names inspected in adjacent PDF rows). Elected prefixes were compared against the results notice. One spelling difference is W6. The stored opening membership contains 120 people; Shohat/Ilatov is correctly distinguished from declared election. Every locality vote column and national total was independently summed. Source and logo SHA-256/SHA-1 checks used Python's standard library. Disposable extraction files are under `.backup-scratch/data-audit/k20-codex/` and are not report dependencies.

Shell HTTP requests with the project User-Agent failed DNS in the restricted environment. Web access successfully read/indexed the sources identified below. The candidate PDF live fetch returned 403, but its retained PDF is readable. Knesset English pages returned a location-denial page; I did not route around it. Original presidential consultation notices were sought by targeted gov.il/president.gov.il searches but not recovered. No challenge, login or paywall was bypassed.
