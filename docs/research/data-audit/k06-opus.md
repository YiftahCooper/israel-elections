# Data audit k06 (2 November 1965, 6th Knesset): Opus auditor

PARTIAL DRAFT, work in progress. Auditor: Claude Opus. Accessed 2026-11-06.

## Non-OK findings so far

1. Letters כס/עס/סס should be כנ/ענ/פש (YP 1230 p.311; YP 1225 p.189; YP 1222).
2. List names: עס "רשימת תנועת לאורה" should be "רשימת התנועה לאחוה"; יא "שיתוף ואחווה" should be "השיתוף והאחוה"; כס "רשימת שלום" should be "רשימת השלום".
3. ב#11 "דיין יחיא שבתי" should be "דון יחיא שבתאי" (YP 1222 p.116 and YP 1230 p.312).
4. Eshkol's PM tenure runs to 1969-03-17 without the acting PM Yigal Allon (from 1969-02-26, per OData).
5. Stale gap: "Six-Day War is dated only to 1967".
6. Coalition includes רא and יא on Hebrew Wikipedia alone; the PM's statement (gov13.pdf) names five factions.
