# k11 independent data audit — Codex

Audited 2026-11-06. Base `2e15191` (contains the required `53cca36`); `git merge --ff-only origin/main` returned “Already up to date.” Auditor role only; no data edits, build, browser suite, push or integration merge.

This is a **partial audit with explicit residual coverage**, not certification of every field. Counts use grouped claim rows: one results row per list (every vote/seat/name/letter in that row), one recommendation row per winning list, and one row per remaining scope/finding. Multiple paths describing the same defect are counted once. Known limitations are classified rather than silently passed. Independently read retained original scans, not just the reviewed JSON; live OData was paginated to completion (127 membership and 148 faction rows).

## Summary

**OK: 65**; **WRONG: 6**; **UNSUPPORTED: 5**; **UNVERIFIABLE: 7**; **DISPUTED: 0**.

Most serious: wrong party identities for `ע` and `ש`; Shiluv’s votes contaminate the Labour-family series; a wrong unelected Alignment candidate name; and a government bloc that renders 98 coalition seats against the primary account’s 97. National vote and seat values themselves pass. No independently established source disagreement remains undecided: primary notices win over secondary numerical mistakes.
