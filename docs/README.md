# Documentation map

Start with the [project overview](../README.md) for the app’s purpose and local setup.

This repository holds what is needed to build the app and to check its numbers. Design specs, review reports,
prior-art studies and other working notes are kept in the project's private archive.

## Where new documents go

- A source, search log or evidence for a fact in the data: `research/<topic>.md`, listed in
  [research/README.md](research/README.md).
- Why the app computes something a certain way: a new record in `decisions/`.
- How a shipped feature works and what it computes: `features/<feature>.md`.
- Design specs, mock-ups, options and questions for the maintainer, prior art, acceptance and review reports: the
  private archive, not this repository.
