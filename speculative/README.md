# Speculative and parked features

Work that was researched or built but is **not part of the app**, because its evidence is not yet solid
enough to ship as a reliable feature (see PRODUCT.md, "Truth over polish"). Each entry says what exists,
why it is parked, and how to bring it back. Nothing here is loaded by the site.

| Feature | Status | Where the work is |
|---|---|---|
| [People-based demographic groups](demographic-groups/README.md) | Parked 4 Nov 2026: no group has a complete, reliable size + turnout + vote-split baseline | branch `speculative/demographic-groups` |

The owner's rule for this area: a feature leaves it only as a reliable feature built on solid data, or as an
opt-in experimental setting that is clearly marked as speculative.
